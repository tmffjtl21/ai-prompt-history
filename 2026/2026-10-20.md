- **[11:02] Q.** `MallCustomerResponse` 형태로 받아와서 바로 넣을 테이블 create문 만들어줄래?
  **A.** `erp_mall_customer`, `erp_mall_customer_sub` 두 테이블 DDL을 `dnm-erp/sql/mall_customer_ddl.sql`에 저장했다. 응답 result set이 `customers`, `customers2` 두 개라 테이블도 두 개로 나눴다. `cst_code`에 UNIQUE KEY, `amep_no`에 인덱스를 둔 MySQL 8 DDL이다.

- **[11:13] Q.** 이 응답 받아서 테이블에 넣는 테스트코드 하나 만들어줘

- **[11:22] Q.** 지금 테이블이랑 우리 거래처테이블(`et_client_base`) 비교해서 없는 컬럼 찾아줄래?

## 이슈와 배운 점
- api-common은 Phase B(api-common-core 라이브러리화) 이후 부팅 설정이 없는 core jar다. 그 안의 `@SpringBootTest`는 뜨지 않으므로 통합 테스트는 shell(`aurora-x2bee-api`)에 둔다.
- shell 통합 테스트는 `useMainMethod = ALWAYS`가 필요하다. 없으면 `ModulePrefixBeanNameGenerator`가 적용되지 않아 도메인 간 동명 빈이 충돌한다.
- `@ActiveProfiles`는 `spring.profiles.active` 프로퍼티를 만들어 주지 않는다. `SwaggerConfig`, `SystemUtil.springProfile()`이 이 값을 읽으므로 static 블록에서 System property로 넣어야 한다.
- 라우팅 DataSource는 RO로 갈 수 있다. 테스트 적재는 `mainRwdbDataSource`를 직접 쓴다.
- dev MySQL MCP는 Access denied 상태다. 조회가 필요하면 shell local 자격증명으로 JDBC 접근했다.
- IF-CST-001 응답의 주소 4칸(`exp_notify1~4`)은 칸 의미가 일정하지 않다(notify2, notify4에 우편번호가 들어오는 경우 있음). `et_client_base` 매핑 시 주의.
- batch-mbod는 sap·erp 의존 없이 `RestApi`로 dnm-gerp를 직접 친다. 전환 시 `global-erp-client` 추가와 `erp-client.yml` import, `eai.*` 설정이 필요하다.
