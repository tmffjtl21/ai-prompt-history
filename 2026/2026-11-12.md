## 이슈와 배운 점
- `brth` NPE: null 확인 없이 문자열 메서드를 호출했다. 선택 입력값은 가공 전에 비어 있는지 먼저 확인한다.
- BO 중복 로그인 NPE: 중복 로그인 응답 분기를 확인하지 않고 쿠키를 구웠다. 예외가 `AppException`이 아니라 500으로 나가 프론트 확인창 흐름이 막혔다. 국내 x2bee 코드도 같다.
- 거래처 NULL 덮어쓰기: `ON DUPLICATE KEY UPDATE`가 받은 값을 그대로 넣는다. 통합회원은 값이 없는 칸을 빼고 보내므로 배치·이전 통지로 들어간 값이 지워진다. 보내지 않는 컬럼은 `COALESCE`로 기존 값을 유지해야 한다.
- `delSyncClientInfo`가 존재하지 않는 테이블 `et_client_info`를 대상으로 한다. 실행되면 SQL 오류가 난다.
- 작업 중 PowerShell에서 함수 이름 `Del`이 내장 별칭과 겹쳐 호출되지 않았다. 스크립트 함수 이름은 별칭과 겹치지 않게 짓는다.
- shell을 로컬에서 `spring-boot:run`으로 띄우려면 api-member를 먼저 `install`해야 반영된다.
- 세션 요약에는 Jenkins 빌드 실패(`.mvn` 설정 추가로 해결)와 `ErpTableLogger` 로그 끄기(yml 설정 추가)도 있다. 오늘 한 일인지는 확인 필요.
