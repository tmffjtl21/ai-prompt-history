## 이슈와 배운 점
- Next 15.5.9 미들웨어의 `req.url`은 Host 헤더가 아니라 서버 리슨 주소 + `x-forwarded-proto`로 만들어진다. ALB 뒤에서 자기 자신을 fetch하면 `https://localhost:9033`으로 가서 실패하므로 `http:` 강제가 필수다.
- 점검 기능처럼 catch에서 로그만 남기고 통과시키는 코드는 운영에서 사실상 꺼져 있어도 드러나지 않는다. 활성화 시점에 비용·타임아웃 영향을 다시 봐야 한다.
- 이미 push된 브랜치는 체리픽이나 reset이 아니라 `git revert`로 되돌린다.
- AI가 git 리셋을 수행하는 동안 GUI에서 브랜치를 전환하면 로컬 ref가 엉킨다. 작업 중에는 GUI 조작을 멈춰야 한다.
- EAI 응답 DTO 구조는 추측하지 말고 스웨거 원본으로 확인한다. `r_err_cod` 오타는 실제로 없고 `r_err_code`가 맞다.
- 공통 응답 상위 클래스의 필드를 지우면 Jackson `ignoreUnknown`으로 값이 조용히 버려져 success가 항상 false가 된다.
- dnm-erp는 Nexus SNAPSHOT으로 배포되므로 소비 모듈(batch, BO)에 반영하려면 install 또는 push 후 CI 배포가 선행돼야 한다.
