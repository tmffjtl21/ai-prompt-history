## 이슈와 배운 점
- **IAM 세션 쿠키 SameSite**: IAM 쿠키가 `SameSite`·`Secure` 미지정이라 크롬이 `Lax`로 본다. http 몰→https IAM은 스킴이 달라 쿠키가 안 실린다. https IAM을 쓰려면 IAM이 `SameSite=None; Secure`로 발급하거나 몰도 https여야 한다. dev(`gdev-fo-mall`, http)도 같은 문제가 생긴다.
- **학생 회원 리다이렉트**: 직종은 토큰 값으로 판단한다. 몰 DB를 고쳐도 바뀌지 않는다.
- **Jenkins SNAPSHOT 해석**: 레포에 `.mvn/settings.xml`이 없으면 Jenkins가 Nexus에서 SNAPSHOT을 찾지 않는다. `withMaven`은 다운로드 로그를 숨긴다.
- **공유 `~/.m2`의 옛 jar**: api-bo는 9월에 install된 옛 common으로 빌드됐을 가능성이 크다. 이제 Nexus 최신 SNAPSHOT을 받으므로 컴파일 오류가 새로 드러날 수 있다.
- **진단 정정**: "Nexus에 artifact가 없다"는 초기 진단은 deploy 로그로 틀렸을 가능성이 확인됐다. 저장소 설정 차이가 실제 원인이었다.
- **줄바꿈**: Edit 도구와 Git Bash awk가 CRLF 파일의 줄바꿈을 바꿨다. CRLF 파일은 바이트 단위로 수정하고 diff 줄 수를 확인한다.
- **기록 불일치**: `CLAUDE.md`에 적힌 설정이 실제 yml에 없었다. 기록만 믿지 말고 파일을 확인한다.
