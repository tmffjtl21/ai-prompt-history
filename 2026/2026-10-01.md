## 이슈와 배운 점
- **메인 500의 실제 원인은 데이터 null이 아니라 빈 배열의 참조 불안정이었다.** zustand 전체 구독 + 렌더마다 새 `[]` 생성 + `useEffect([파생값])`에서 set 호출이 조합되면 무한 루프가 된다. 코너 컴포넌트에서 스토어는 셀렉터로 구독하고 effect 의존성은 원본 prop을 쓴다.
- **화면의 "500"은 HTTP 500이 아니라 `error.tsx` 바운더리 화면이다.** 이 파일은 error prop을 받지도 로그도 남기지 않아 원인을 화면에서 알 수 없다. 서버 터미널 또는 브라우저 콘솔을 먼저 본다.
- **restApi는 예외를 던지지 않고 비JSON 응답이면 payload가 문자열이 된다.** `(payload || [])` 패턴은 빈 배열 대신 문자열을 반환해 `.filter` 등에서 터진다.
- **CLAUDE.md는 상위 경로 전부가 합쳐 로드된다.** 공통 지식은 위로 올리고 레포 파일은 함정만 짧게 쓰면 탐색 호출이 절반 이하로 줄어든다. 새 함정을 알게 되면 그 자리에서 한 줄 추가하는 습관이 효과가 크다.
- **Atlassian MCP v1 SSE 엔드포인트는 지원 종료 예정이다.** v2 엔드포인트로 설정을 바꾸고 재인증해야 한다.
- 지난 9월 18일 테스트에서 `ME_MBR_AST_SUM` 잔액 NULL은 api-bo 수기 소멸 SQL의 NULL 전파였고 COALESCE로 수정 반영됐다.
