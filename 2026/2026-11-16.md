## 이슈와 배운 점
- Dooray API가 전면 중단돼 MCP 호출이 `socket hang up`으로 실패했다. 인증 거부가 아니라 연결 끊김이면 토큰 문제가 아니다.
- 토큰을 대화에 평문으로 붙여 넣었다. 대화 기록을 외부에 공유하지 않도록 주의한다.
- 웹훅 URL이 소스에 하드코딩돼 있다. URL만 알면 누구나 대화방에 메시지를 보낼 수 있다.
- `ME058.java`와 정의서에 `END_CRD` 오타가 있었다. DB 값은 `DEN_CRD`라서 직종이 빈 값으로 저장되고 있었다.
- `x2bee_global/CLAUDE.md`의 기록과 실제 코드가 달랐다. 전화번호 분할 교체가 반영돼 있지 않았고, ME060 SQL 파일도 없었다.
- 개발 DB의 ME060 공통코드가 옛 정의라 BO 화면의 코드명이 어긋난다.
- 3칸 전화번호 구조는 한국 번호 전용이다. 일본은 지역번호 길이가 달라 하이픈 없이는 나눌 수 없다.
- 번호 앞자리 0을 직접 자르는 로직은 두지 않는다. 국가마다 접두 번호 규칙이 다르다.
- 첫 칸이 varchar(10)이라 번호 원문 저장 시 `Data too long`으로 테스트 23건이 실패했다. DDL 적용 후 해소됐다.
- api-bo `target`에 지워진 GERP 매퍼 XML 6개가 남아 스프링 컨텍스트가 뜨지 않았다. `target`의 해당 파일만 지워 해결했다.
- 20자는 현재 NETRA 최대 길이와 같다. 21자 이상이 오면 저장에 실패한다.
